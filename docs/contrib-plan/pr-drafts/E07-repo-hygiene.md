## Summary

Untracks 101 files that are build output or superseded copies, taking the tracked tree
from 95.3 MB to 18.6 MB, and repairs `.gitignore` patterns that silently match real
source files. Adds `.gitattributes`, `.mailmap`, `.editorconfig` and `.clang-format`.

No file is deleted from history. Everything removed is reachable with `git show` and
`git log --follow`.

## Motivation

### The `.gitignore` patterns match sources

The file uses `**build**` and `**install**`. Outside the three special forms (`**/`,
`/**`, `/**/`), consecutive asterisks collapse to a single `*`, so these match any path
containing the substring anywhere:

```
$ git check-ignore --no-index -v higtree/src/build-fringe.cpp
.gitignore:73:**build**  higtree/src/build-fringe.cpp

$ git check-ignore --no-index -v install_higflow_arch.sh
.gitignore:74:**install**  install_higflow_arch.sh
```

`build-fringe.cpp` is compiled by both build systems. It survives only because it was
committed before the rule existed — deleting and re-adding it would silently drop it.
The same rule swallows `install_higflow_arch.sh` from the `PC_ImproveDocumentation`
branch, and anything under `docs/install/`.

Global `*.txt`, `*.dat` and `*.vtk` rules were also hiding legitimate files, which is
why the file needed a `!CMakeLists.txt` exception to undo part of its own damage.

### PETSc

`bibliotecas/` is listed in `.gitignore`, but the rule was added after the archive was
committed, so it had no effect. `bibliotecas/fetch-petsc.sh` now downloads the archive
from the Argonne release snapshots and verifies it against the SHA-256 of the archive
that was previously committed, so the build receives byte-for-byte the same source.
Both mirrors were confirmed to serve an archive of exactly the committed size. The
script is idempotent and is called from `install_higflow_ubuntu22` and the Singularity
`petsc.sh`.

`libfyaml-master.zip` is deliberately left in place — it is a snapshot of upstream
`master` rather than a tagged release, so no stable URL reproduces it. Replacing it
means choosing a release to pin to, which changes the library the project builds
against; that is a maintainer decision, not cleanup.

### On the style files

`.editorconfig` and `.clang-format` describe the convention already present; they are
not an instruction to reformat. Indentation was measured over the 58 non-superseded
source files:

```
higflow/src   tabs    643 ( 1%)   spaces  39617 (98%)
higtree/src   tabs   8368 (89%)   spaces    954 (10%)
```

The two halves genuinely differ, so `higtree/` carries its own `.clang-format` that
inherits the root configuration and overrides only the indentation. Brace placement
(944 attached against 440 detached) and pointer alignment (4047 `type *name` against
108 `type* name`) were counted the same way. `ColumnLimit` is `0` so clang-format never
rewraps a line it was not asked to change.

Running clang-format over the tree is explicitly **not** proposed: it would rewrite
blame across 176,000 lines and make merging the unmerged branches impractical.

## Notes for reviewers

**1. `higflow/src/src_hugo/` was deliberately left alone.** It is a 2.4 MB parallel copy
of the source tree, including a directory whose name contains spaces
(`Modifications of files viscoelastic flows with variable viscosity/`), which breaks
naive Makefile and shell handling. It appears to be another researcher's working copy,
so removing it is not the contributor's call. **Should it move to a branch, or stay?**

**2. Two decisions about the git history were deliberately not taken.** The history
still contains a 45 MB `.avi`, VTK outputs of 38 MB and 20 MB, and a full `atf-0.15/`
tree with test binaries — roughly 160 MB that `git filter-repo` would remove. That
rewrites every SHA and breaks every existing clone and branch, so it is not something a
contributor should do by pull request. Flagged for the owners to decide.

**3. `install/` is ignored** because `CMakeLists.txt` sets `INSTALL_PATH` to
`<source>/install` when no prefix is given. Installation *scripts* therefore need a
different location — `scripts/install/` — or they land in an ignored directory. Noted
in the `.gitignore` comment.
