◆ hs_deserialize_n()

size_t hs_deserialize_n ( hig_deserialization_ctx * hsd,
hig_serial_tree * buf,
size_t count )

Deserializes at most count elements into hig_serial_tree.

At every invocation of this function, at most count nodes are processed from the array buf. Deserialization context must have been initialzied with hs_deserialization_start().

It is safe to pass a count greater than the number of nodes needed to complete the tree, in this case, the extra elements will be ignored.

Returns
the number of nodes deserialized. This is count unless the deserialization is complete, in which case the actualy used to deserialize the tree.

size_t hs_serialize_n ( hig_serialization_ctx * hss,
hig_serial_tree * buf,
size_t count )

Serializes at most count elements into hig_serial_tree.

At every invocation of this function, at most @count of the remanining nodes of the tree are serialized. Serialization context must have been initialzied with hs_serialization_start().

Returns
the number of nodes serialized. This is count unless there is no more nodes to serialize, in which case the value returned is shorter. Zero is returned if the serialization is over.
