◆ lb_add_input_tree()

void lb_add_input_tree ( load_balancer * lb,
hig_cell * tree,
bool managed,
unsigned group )

Adds a local tree to be partitioned and distributed.

Is not a collective call. Each process may add zero or more trees to be redistributed. Each tree is entitled to a group, that will define the weight of its leaves.

This function must be called before lb_calc_partition().

Parameters
lbPartition context created with lb_create().
treePointer to the tree to have its nodes redistributed.
managedTells if the partitioning can change the trees in-place. If managed is true, the memory management of the tree is handled by the load-balance procedure, and may be modified or even freed by it, and may be part of the output trees. If managed is false, the original tree will be left unchanged after the procedure, and the corresponding (possibly modified) output tree will be a clone.
groupThe id of the group the tree will belong to.

void lb_add_portal ( load_balancer * lb,
const Rect * a,
const Rect * b,
unsigned group )

Adds a space warping portal connecting two remote areas of the domain.

This is a collective call. All portals must be specified in the same order for all processes. Used for periodic domains.

Rects a and b must have exactly the same size, and must have exactly one dimension with size 0. These preconditions are enforced with assert(). The caller is responsible for sanitizing user input.

The behavior of portals is well defined if, and only if: 1) they are placed on the limit of a tree and free space; 2) there is enough free space behind the portal, so a fringe fits there; 3) a-side wall must face the opposite direction of b-side wall.

◆ lb_create()

load_balancer * lb_create ( MPI_Comm comm,
unsigned num_groups )

Creates the context for partitioning HigTrees among processes.

Creates a context for distributed load-balance partitioning of trees among all process in MPI communication group comm.

This is a collective call, and must be performed by all process in comm.

Parameters
commAn MPI communication group containing all process that will take part on the partition.
num_groups

Trees taking part in partition are organized in groups. Each group has its own weight, and each tree will be kept in its own group after the partitioning.

Groups are useful in differentiating trees of the boundary conditions from trees of the internal domain, for instance.

This parameter num_groups gives the number of groups that will be used on this partitioning, and must be given the same for all processes in MPI group comm. Must be 1 or more. Tree groups are identified from 0 to (num_groups - 1).

Returns
The parallel load-balance context to be passed to other parallel load-balance related functions. Must be freed with lb_destroy().

◆ lb_get_local_tree()

hig_cell * lb_get_local_tree ( load_balancer * lb,
size_t idx,
unsigned * group )

Retrieve a tree after the load balancing.

Is not a collective call. Must be called after lb_calc_partition().

Each call to this function will return one of the trees in the new, balanced, partition, indexed by idx. Indexes starts from 0, and must be less than the total number of trees, as given by lb_get_num_local_trees() function.

Each tree that can be returned by this function must be managed by the caller, and it is an error to not retrieve all the available trees.

Parameters
idxThe index of the output tree. The output trees are ordered and grouped by their group's ids, so trees from group 0 have the lower idx values, from group 1 have the next ones, and so forth.
[out]groupA pointer to be filled by the tree's group's id. May be NULL, if you don't need that information.

Is not a collective call, but fringe will be generated only between process that set this true to the that group.

◆ lb_set_group_weight()

void lb_set_group_weight ( load_balancer * lb,
unsigned group,
float weight )

Sets the weight the leaves of the trees in the group will have in the partitioning.

Is not a collective call, and will affect only the group's trees supplied by the calling process.

By default, group 0 have weight set to 1.0, and other groups have it set to 0.0001.

This function must be called before lb_calc_partition().

Parameters
lbPartition context created with lb_create().
groupGroup's id whose weight will be set.
weightThe weight of each tree leaf in the partition, default is 1. Set to 0 if you don't want the trees of this group to affect the partitioning.
