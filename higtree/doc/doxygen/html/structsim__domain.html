Detailed Description

A simulation domain (SD) contains a set of HiG-Trees which composes.

An SD has a set of dirichlet BCs and a set of neumann BCs. An SD has an interpolator, which can be used multiple times without needing The cwls keeps the interpolation within a cell (it is a cached interpolation).
